# Changes

## 2026-11-19 v1.5.0

### Build & CI

- Bumped the minimum required version of the `gem_hadar`
  development dependency to **2.24.1**.
- Updated the `rubygems_version` metadata in the gemspec to
  **4.0.24**.
- Removed Vim modeline comments from `Gemfile` and `Rakefile`.

### Documentation

- Added a header comment to `lib/file/tail/version.rb` explaining
  that the file is auto-generated by `GemHadar` and should not be
  edited manually.
- Updated the inline comment for the `VERSION` constant in
  `lib/file/tail/version.rb` to clarify it represents the current
  version as a String.

## 2026-01-02 v1.4.0

### Fixes
- Fixed a race condition during file rotation where lines could be
  skipped by handling `Errno::ENOENT` and `Errno::ESTALE` separately.
- Resolved an issue where the buffer size parameter was not passed
  correctly due to a typo in the `Logfile` class.
- Corrected typos in code comments and the `README.md`.

### Improvements
- Added nil safety checks for file paths in test cleanup routines.
- Removed unnecessary local variable assignments in the `rtail`
  binary.
- Renamed `COPYING` to `LICENSE` for better standard compliance.

### Build & CI
- Added CI support for Ruby **4.0** and updated Alpine package
  dependencies.
- Removed CI support for the Ruby **3.0** Alpine image.
- Updated the Dockerfile to simplify dependency installation and add
  Ruby **3.4**-alpine support.
- Updated gemspec metadata, including `rubygems_version` to **4.0.2**
  and `gem_hadar` dependency to `>= 2.16.3`.
- Added `LICENSE` and `.github/workflows/static.yml` to the gemspec
  file list.
- Configured automated changelog generation in the `Rakefile`.

### Testing
- Updated tests to use the `tmp` directory for test files and added
  it to git tracking and ignore lists.
- Added `.yardoc` to gitignore and rake ignore lists.

### Documentation
- Replaced `README.md` content with a comprehensive architecture
  overview, usage examples, and debugging sections.
- Added a GitHub Actions workflow for automated documentation
  deployment using Ruby **3.4**.

## 2024-09-13 v1.3.0

### Fixes
- Replaced hardcoded `$DEBUG` checks in `File` with a new `debug?`
  method that checks the `FILE_TAIL_DEBUG` environment variable.
- Added an `at_exit` handler to clean up temporary test files created
  during test setup.

### Improvements
- Converted `CHANGES` to `CHANGES.md` and updated the gemspec to
  reference the new filename.
- Updated the test suite to use absolute paths for temporary files.

### Build & CI
- Added conditional Ruby version checks in the Dockerfile to handle
  `gem update` and `bundler` installation variations.
- Updated the Gemfile and Rakefile to target Ruby **3.5.18** and
  replaced `bundle` with `bundle install` in the test script.
- Added new development dependencies: `all_images`, `simplecov`, and
  `debug`.
- Updated `gem_hadar` to **1.17.1**, `test-unit` to **3.0**, and
  `tins` to **1.0**.

### Testing
- Increased timeout values from 2 to 10 seconds in tests to improve
  reliability when waiting for log output.
- Updated test logic to wait for specific line counts instead of
  relying on thread stop signals.

## 2017-04-13 v1.2.0

### Breaking
- Changed the license from GPL v2 to Apache 2.0.

### Features
- Added a `line_separator` attribute to `File::Tail` to allow customizing the line separator.

### Fixes
- Fixed `backward` and `forward` methods to correctly use the configured `line_separator` instead of the default newline character.
- Corrected the default value of `line_separator` to reference the global `$/` variable instead of the string `"$/"`.
- Ensured the file is reopened when the inode changes, preventing errors during log rotation with copytruncate.

### Improvements
- Updated the README from RDoc to Markdown format and revised the installation and usage documentation.
- Simplified the `Rakefile` by removing the custom `install_library` task.

### Build & CI
- Added Ruby **2.4.1** and updated the **2.3** version to **2.3.3** in the CI configuration.
- Updated the development dependency `gem_hadar` to version **~> 1.9.1**.

## 2011-06-25 v1.0.6

### Features
- Introduced `File::Tail::Group` to manage and tail multiple files
  concurrently.
- Added `File::Tail::LineExtension` to attach file context information to
  each tail line.
- Added `-n` option to `rtail` to display the last number of lines in
  tailed files.
- Added `-M` option to `rtail` to prefix each output line with the source
  file name.

### Improvements
- Restructured library code by separating `File::Tail::Logfile`,
  `File::Tail::Tailer`, and other components into dedicated files.
- Renamed `README` to `README.rdoc` and updated documentation generation
  to use `sdoc`.
- Updated `rtail` to use `File::Tail::Group` for managing log file tails.
- Renamed `debug` method to `output_debug_information` in `File::Tail`.
- Added `default_bufsize` attribute to `File::Tail` to allow customization
  of backward search buffer size.

### Build & CI
- Updated `spruz` dependency requirement to `~> 0.2`.
- Added `Gemfile` with `spruz` and development dependencies `sdoc` and
  `rcov`.
- Updated `Rakefile` to use `Gem::PackageTask`, install `rtail`
  executable, and dynamically generate gemspec.
- Updated `.gitignore` to ignore dotfiles and `doc` directory.
- Removed `install.rb` and `make_doc.rb`, replacing their functionality
  with Rake tasks.

### Testing
- Added test suite for `File::Tail::Group`.
- Added tests for `backward` method with custom buffer sizes and
  `default_bufsize`.
- Renamed `TC_FileTail` test class to `TestFileTail`.
